# Customer Revenue Prediction 💰

## Overview
Predicted customer revenue segments using ML models on 8,124 customer records across 32 variables.

## Key Results
- 98% accuracy with Random Forest
- 80% recall on high-value customer identification
- Improved targeting efficiency by 25%

## Tech Stack
Python | Scikit-learn | Pandas | NumPy | Matplotlib | Seaborn

## Files
| File | Description |
|------|-------------|
| `revenue_prediction.ipynb` | Main analysis notebook |
| `dataset.csv` | Customer dataset |

## Steps
1. Data Cleaning & EDA
2. Feature Engineering (8 categorical encodings)
3. Outlier treatment (2.5% capping)
4. Model Comparison (5 ML models)
5. Random Forest Final Model
